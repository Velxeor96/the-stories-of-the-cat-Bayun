# Обучение (tutorial)

Здесь будет обучающий модуль, который ведёт игрока через ключевые механики:

1. **Проснуться на корабле** — базовое описание, что видит игрок.
2. **Осмотреться** — проверка навыка `Per` (Восприятие).
3. **Найти предмет** — карточка «ПОЛУЧЕНО В ИНВЕНТАРЬ».
4. **Поговорить с NPC** — проверка `Fel` (Общительность).
5. **Перейти в другую локацию** — событие `location_change`.
6. **Финальный экран** — «Ты прошёл обучение», выход в обычную игру.

## Что кладём в эту папку

- `script.md` или `script.yaml` — линейный сценарий с репликами Мастера
  и ожидаемыми действиями игрока.
- `prompts.txt` — отдельный промпт Мастера для режима обучения
  (если хотим другой тон — мягче, объясняющий).
- Опционально: `checks.json` — какие именно проверки должны быть пройдены.

## Как это подключится

- `ui/screens/tutorial.py` — рендерер (заглушка уже есть).
- Точка входа — кнопка «🎓 Обучение» в сайдбаре игрового экрана.
- Флаг `st.session_state.tutorial_mode = True` — пока играем в туториале.
- По завершении — `tutorial_mode = False` + сохранить `seen_tutorial = True`
  в `data/users/{login}/settings.json`.

**Готовый модуль из другого чата сюда и вставим.**
