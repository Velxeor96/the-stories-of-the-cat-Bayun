# 1.7.0 — Alpha (30.09.2026)

## Новое
- **Race Lock**: мастер больше не путает расу игрока. Эльдар не «моно-кеи», орк не «человек», некрон не «гуманид». Трёхуровневая защита: system prompt + первое сообщение + напоминание.
- **Закупка характеристик**: 200 очков на пул, до +35 на характеристику. Live-preview «Итог» и «Прогноз с бонусами родного мира».
- **Фракционные стартовые наборы**: своё оружие, броня, таланты, навыки, деньги для Империума, Хаоса, Эльдар, Орков, Тау, Некронов, Друхкари, Тиранид, Генокрадов.
- **Бонусы родных миров и карьер** применяются автоматически.
- **Кнопки чата**: Осмотреться / Говорить / Атака / Иное — стабильно работают.

## Исправления
- `game.py` — кнопки не теряют `_pending_chat` при rerun.
- `master.py` — жёсткий race-lock, запрет на выдумывание локаций.
- `data_loader.py` — whitelist вместо парсинга мусора.

## Известные ограничения
- chroma_db (75 МБ) — в `.gitignore`, при первом запуске на новой машине надо собрать `python scripts/build_embeddings.py`.
- Портреты персонажей не генерируются.
