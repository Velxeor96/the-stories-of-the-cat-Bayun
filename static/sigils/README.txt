Сиглы фракций — SVG (приоритет) или PNG.

Файлы с этими именами:

  dark.svg           (или .png) — нейтральная
  imperial.svg                  — Империум (Аквилла)
  mechanicum.svg                — Механикум (шестерня+череп)
  imperial_guard.svg            — Имперская гвардия
  tau.svg                       — Тау
  eldar.svg                     — Эльдары
  necrons.svg                   — Некроны
  orks.svg                      — Орки
  tyranids.svg                  — Тираниды

Приоритет: .svg, потом .png, потом встроенный fallback.

SVG: рекомендуется viewBox="0 0 N N" без width/height на корне —
код сам подставит размер и инвертирует цвета для тёмных тем
(чёрный символ станет белым).

PNG: квадратные, 512x512+. Инвертируются так же.

После копирования файлов перезапусти Streamlit.
